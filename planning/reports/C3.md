Styles are injected into the supplied container (Shadow DOM safe). Strings use `textContent` only.

## Behaviour CORE can rely on

- **Check this store** is shown only when `supported` is true; disabled while busy / in-flight.
- **Current site** is `originLabel` (fallback copy if blank). No invented hostname.
- **Automatic checks** render as enabled only when `siteAccess === 'granted'`. Manual copy states this-tab access, not site-wide background permission.
- **Allow automatic checks** is shown on supported + manual pages (CORE implemented host permissions in `popup-entry.js`).
- **Stop automatic checks** is shown only when granted.
- **Motion** Follow system / Reduce motion → `SET_MOTION`.
- **Unsupported** is a limitation banner, not a failed scan. Loading (`originLabel` matching `/loading/i`) does not use that banner.
- **Permission rejection / runtime error** is visible from `state.error` or `RuntimeReply.message`.
- Host-access buttons can be hidden in the view model via `hostAccessImplemented: false` if CORE later drops those actions.
